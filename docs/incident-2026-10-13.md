## 根因（分层）

1. **击键路径同步阻塞（主因）**：librime-lua filter 是同步模型，每个完整词的 LLM 查询（本机 CPU 150–500ms）+ 方案冷加载（本机秒级）都发生在宿主应用 UI 线程的同步 COM 调用里。查询成功与否无关紧要——**阻塞本身就是冻结**。
2. **进程 churn（放大器）**：部署拉起第二台 WeaselServer 而旧的不死，TSF 会话在两台间分流，每次切换都可能再触发一次冷加载。
3. **部署器堆积（回滚返工的原因）**：多次 `/deploy` 实例并存（遗留 pid 13640 长期存活），互相用各自记忆的状态改写 default.custom.yaml（并按字母序排 schema_list）。教训：**部署前后必须盘点 deployer/server 进程，单实例纪律**。
4. 证据排除：popen 挂起（服务端两次查询都返回）、lua 代码缺陷（日志干净）、熔断失灵（无失败可言）。
